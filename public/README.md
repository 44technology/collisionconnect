# Public assets

Bu klasördeki dosyalar olduğu gibi site kökünden sunulur.

## Fixly logosu

Logonun tüm sayfalarda görünmesi için PNG dosyanızı şu isimle bu klasöre koyun:

**fixly-logo.png**

Yani:
- Dosya yolu: `public/fixly-logo.png`
- Tarayıcıda: `http://localhost:5173/fixly-logo.png`

Logo şu yerlerde kullanılıyor:
- Ana sayfa (HeroSection, Footer)
- Müşteri paneli (Dashboard)
- Admin paneli (AdminDashboard)
- Body shop paneli (ShopDashboard)
- Teklif sayfası (QuotePage)

Dosyayı koyduktan sonra sayfayı yenileyin; ekstra bir sayfa veya ayar gerekmez.
